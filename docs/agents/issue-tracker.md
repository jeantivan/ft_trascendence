# Issue tracker: GitHub

Issues for this repo live in GitHub. Use `gh issue` CLI or the web interface.

## Workflow

- Create issues with `gh issue create --title "..." --body "..."`
- List issues with `gh issue list`
- View an issue with `gh issue view <number>`
- Update status with labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`
- Link related issues using GitHub's linking feature or mention in descriptions

## Labels

See `triage-labels.md` for label meanings and usage.
